## Session recaps

Each session has four recaps. Start with **Previously On** for a quick refresher, or open the **Campaign Ledger** to see every open lead.

| Session | Date | Previously On | Scene Recap | Character Spotlights | Campaign Ledger | Transcript |
|---|---|---|---|---|---|---|
| 01 | 2026-09-29 | [Read](Summaries/Previously_On/Session_01_Previously_On.md) | [Read](Summaries/Scene_Recaps/Session_01_Scene_Recap.md) | [Read](Summaries/Character_Spotlights/Session_01_Character_Spotlights.md) | [Read](Summaries/Campaign_Ledger/Session_01_Campaign_Ledger.md) | [Read](Recordings/Session%2001/Session_01_Readable.md) |

**What each recap is:**
- **Previously On:** a short recap to read aloud at the start of the next session.
- **Scene Recap:** the session scene by scene, with the NPCs, clues, rolls and loot from each.
- **Character Spotlights:** what each hero did, said and gained.
- **Campaign Ledger:** quests, NPCs, places, loot, decisions and every open thread.
